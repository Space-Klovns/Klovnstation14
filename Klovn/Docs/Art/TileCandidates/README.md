# Artbook tile candidate sets

Seven complete, selectable tile-art collections generated from monolithic atlases according to [`spritegen.md`](../../spritegen.md). Each set is isolated and contains the original atlases plus the extracted game-ready sheets under `Tiles/`.

Each set contains 82 opaque PNG sheets at exactly 128×32 pixels. Each sheet contains four 32×32 tile variants. The collection covers Cloud Civilian, Orbital Civilian, Orbital Syndicate, and Cloud Royal steel, maintenance, and Royal decorative tiles. Cloud Civilian maintenance follows the Artbook's three requested conditions; Orbital Civilian maintenance uses pale space dust; the other listed families use all four conditions.

| Set | Geometric direction |
| --- | --- |
| [Set 01](Set-01/) | Raised angular plate baseline |
| [Set 02](Set-02/) | Chamfered octagonal plates |
| [Set 03](Set-03/) | Straight diagonal braces |
| [Set 04](Set-04/) | Offset service hatches |
| [Set 05](Set-05/) | Clipped-corner plates and double bevels |
| [Set 06](Set-06/) | Diamond-oriented panel geometry |
| [Set 07](Set-07/) | Central square hatches and support brackets |

`Preview.png` in each set shows its 82 sheets with labels. `Atlases/` retains the generated source art; `Tiles/` contains ready-to-review 128×32 sprite sheets. These are selection candidates and have not been installed into the live `Resources/Textures` paths.
