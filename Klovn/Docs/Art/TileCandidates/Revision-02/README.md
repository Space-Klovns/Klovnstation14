# Tile Candidates — Revision 02

This revision contains the regenerated tile candidates requested from the Artbook tile list, plus Orange Beaks tiles. Nothing here replaces the live game textures; these are review candidates only.

Each sprite sheet is exactly 128×32 (four 32×32 variants). Source atlases are retained alongside the cut sheets, and each set has a labeled `Preview.png` contact sheet.

## Artbook tiles

Seven complete faction sets, 80 sheets each (560 sheets total): Cloud Civilian, Orbital Civilian, Orbital Syndicate, and Cloud Royal. Each set includes the steel and maintenance/decorative categories and condition variants specified in the Artbook. Maintenance designs are distinct from steel plating.
