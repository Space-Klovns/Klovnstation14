# Native procgen examples

These maps are generated by the actual procgen planner and verified through native save/load.
Images now come exclusively from `Content.MapRenderer`:

- [Tiny strip](Native/tiny-strip/tiny-strip-0.png)
- [L shape](Native/l-shape/l-shape-0.png)
- [Kitchenette](Native/kitchenette/kitchenette-0.png)
- [Gas room](Native/gas-room/gas-room-0.png)
- [Wired office](Native/wired-office/wired-office-0.png)

The YAML files here and in `Resources/Maps/_KS14/ProcgenShowcases` are native map inputs. Request,
content and diagnostic JSON/YAML files record generation inputs and outcomes, not rendering rules.
The old custom gallery, PNG/SVG composites, sprite mappings and sprite manifests are removed.

Regeneration and direct native rendering commands are documented in
[the tool README](../../../../Tools/_KS14/Procgen/README.md). Native images use `--wires-last` so
installed cables appear above floors and furnishings. Normal map rendering remains available
without that option. These examples do not certify operational power supply or map publication.
